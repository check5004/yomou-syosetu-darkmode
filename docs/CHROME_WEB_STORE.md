| 項目 | 内容 |
| --- | --- |
| 登録料 | 開発者アカウントの初回登録時に5米ドル。年会費ではありません。日本円の請求額や決済条件は支払い画面で確認します。 |

初回料金は[Google公式の2026年4月の案内](https://developer.chrome.com/blog/cws-role-expansion-developer-dashboard)、一度きりの登録料であることは[開発者登録手順](https://developer.chrome.com/docs/webstore/register)を参照。審査期間は[公式の審査プロセス](https://developer.chrome.com/docs/webstore/review-process)によります。3週間を超えて保留が続く場合の問い合わせ先も掲載されています。

### 単一目的

```text
「小説を読もう！」と「小説家になろう」の対象閲覧ページをダークモードにし、配色と任意の本文文字調整によって小説を探す・読む際の表示を整えます。
```

### storage権限の理由

```text
ユーザーが選んだ表示モード、配色、本文の文字調整のオン／オフ、文字サイズ、行間をchrome.storage.localに保存し、再訪時と開いている対象ページへ反映するために使用します。保存するのは表示設定のみで、外部サーバーには送信しません。
```

### 対象サイトへのアクセス理由

ホストアクセスやコンテンツスクリプトの説明を求められる欄には次を使用します。

```text
対応ページに同梱のCSSとJavaScriptを適用し、背景色・文字色・読書用の表示を変更するためです。対象範囲はmanifest.jsonで指定したページに限定し、ページ内容や入力情報を収集・保存・送信しません。
```

### リモートコード・データの扱い

- リモートコード：使用しない。実行するコードはすべて拡張機能ZIPに同梱。
- データ収集：現在の実装では個人情報・閲覧履歴・サイト内容などを収集せず、表示設定だけを端末内に保存。
- 売却・無関係な目的への利用・信用判断への利用：いずれも行わない。フォームの確認文を読み、実態に一致するチェック項目を確定する。
- プライバシーポリシー：上記の公開URLを指定。

Chromeウェブストアの[プライバシー入力欄](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)は、コードの実際の挙動・ポリシー本文・申告内容を一致させて記入します。

## 登録から公開までの順番

1. 本人がGoogleアカウント・2段階認証・初回料金・開発者プロフィールを設定する。
2. ストア用の画像と最終ZIPを用意する。
3. [Developer Dashboard](https://chrome.google.com/webstore/devconsole/)で新規アイテムを追加し、ZIPをアップロードする。
4. 掲載情報・プライバシー・配布設定・テスト手順を入力する。
5. 必須項目と実態の一致を確認し、審査へ提出する。
6. 承認後に公開し、ストア版でインストール・配色・設定保存を確認する。
7. ストアのURLをREADMEに追加する。

審査後に自動公開するか、承認後に手動で公開するかを選べます。手動公開で承認された場合、公開猶予は30日です。[公式の公開手順](https://developer.chrome.com/docs/webstore/publish)

現在のGitHub ActionsはGitHub ReleasesへのZIP配布までを行います。Chromeウェブストアへの初回登録・画像入力・申告・審査提出は別作業です。更新自動化は、ストアのアイテムID取得後に必要性を判断します。
